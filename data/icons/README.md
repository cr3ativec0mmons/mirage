# Application icons

These are simple placeholder icons of a mirror. Replace them following the
[GNOME icon guidelines](https://developer.gnome.org/hig/guidelines/app-icons.html),
keeping the file names:

| File                                                        | Purpose                                                    |
| ----------------------------------------------------------- | ---------------------------------------------------------- |
| `hicolor/scalable/apps/tech.vitainside.mirage.svg`          | Full-color icon                                            |
| `hicolor/scalable/apps/tech.vitainside.mirage.Devel.svg`    | Development build icon, with the striped "nightly" overlay |
| `hicolor/symbolic/apps/tech.vitainside.mirage-symbolic.svg` | Symbolic icon, shared by both builds                       |

Icons used inside the interface live in `data/resources/icons`.
